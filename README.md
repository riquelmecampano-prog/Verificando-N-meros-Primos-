# 🔢 Verificador de Números Primos em Python

Projeto desenvolvido em Python para verificação, lógica de algoritmos e listagem de números primos, aplicando estruturas de repetição, condicionais e funções.

## 🚀 Tecnologias Utilizadas

* **Python 3.x**
* **Git e GitHub** (controle de versão)

## 📌 Funcionalidades

- **Verificação individual:** Identifica se um número específico é primo ou composto.
- **Listagem de intervalos:** Gera uma lista com todos os números primos entre 1 e 100.
- **Tratamento de exceções:** Validação para números menores ou iguais a 1.
